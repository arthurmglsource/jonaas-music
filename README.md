# JONAAS — Website Oficial

Website oficial e editorial de JONAAS — Música, discografia, vídeos e contactos.

## 🚀 Funcionalidades
- **Abertura & Identidade:** Monograma, logotipo vetorial e animações personalizadas.
- **Música & Single:** Destaque de faixas, links de streaming (Spotify e YouTube).
- **Discografia:** Lançamentos com player e links oficiais.
- **Podcasts & Performance:** Apresentações e entrevistas selecionadas.
- **Biografia & Contacto:** História, trajetória e canal direto de booking.

## 🛠️ Tecnologias
- HTML5 semântico
- CSS3 puro (Motion design e responsividade)
- JavaScript nativo

## 💻 Executar Localmente
```bash
python3 -m http.server 4173 --directory dist
```
Aceder a [http://localhost:4173](http://localhost:4173).
